# Link_Click_Fan_Theory_Website
A website to share fan theories I have and have other people to read them for fun. Link Click is a Donghua directed by Li Haoling and produced by Studio LAN with help of the director's own studio, Haoliners Animation League. This is fan work.

## Details:
A website for me to share theories with other Link Click Fans! The original idea was to have a space on each page so people could discuss and comment on them but I'm not exactly sure for to do that, I'll learn on the future! This website if for fun, by a fan for fans. It consists of the index page, character profile, season2( I'm still writing the theories for season 2 and Bridon Arc) and A Bridon Arc page. Use the Navigation box on the top left corner to quickly access any page you're interested in checcking. This website has personalized text-highlights and slider so feel free to use them!. I am planning In updating this website on the future with all the features I had planned at the begining.
